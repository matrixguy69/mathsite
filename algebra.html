1. Algebraic notation and like terms

Letters in algebra stand for numbers we do not know yet. Every rule of arithmetic still applies, so you can add, subtract, multiply and divide expressions exactly as you would with ordinary numbers, once you respect one rule: only like terms can be collected.

ShorthandMeans
3x3 times x
x²x times x
5ab5 times a times b
x/4 or ¼xx divided by 4
2(x + 3)2 times everything in the bracket

1.1 Like and unlike terms

Like terms have exactly the same letters with the same powers. Unlike terms do not, and they can never be merged.

3x + 2x = 5x · 3x + 2y stays as it is · 4x² + 3x² = 7x² · 4x² + 4x is NOT 8x²

Terms with different powers are also unlike: x² + x cannot be simplified further, and neither can 3x + 3x².

1.2 Substituting values

To substitute, replace every letter with its value in a bracket, then use order of operations (brackets, then powers, then multiply and divide, then add and subtract). A negative number in a bracket needs care with its power.

Worked example 1

Simplify 3x + 2x − 4y + 7y + 2x².

  1. Circle the like terms: 3x and 2x are both "x" terms; −4y and 7y are both "y" terms.
  2. 3x + 2x = 5x
  3. −4y + 7y = 3y
  4. 2x² has no partner, so it stays alone.

5x + 3y + 2x²

Worked example 2

Given x = −2 and y = 5, evaluate 3x² − 4x + 1 and 2y − 3x.

  1. Substitute with brackets: 3(−2)² − 4(−2) + 1
  2. Powers first: (−2)² = 4, so 3 × 4 = 12
  3. Then −4(−2) = +8, so 12 + 8 + 1 = 21
  4. Second expression: 2(5) − 3(−2) = 10 + 6 = 16

3x² − 4x + 1 = 21 and 2y − 3x = 16

Exam trap(−2)² = 4 but −2² = −4. The bracket decides whether the negative is inside the power. Also 3x² means 3 × x × x, never (3x)².
Exam tipWrite 2a not a2, and put terms in order of decreasing power: 2x² + 5x − 1. Examiners award method marks for tidy, ordered working.

2. Expanding brackets

Expanding means removing the brackets by multiplying everything inside by whatever is outside. The law that makes it work is the distributive law:

a(b + c) = ab + ac · a(b + c + d) = ab + ac + ad

2.1 Single brackets

Worked example 3

Expand 3(x + 5), −2(4 − 3x) and 4x(2x − 3).

  1. 3(x + 5) = 3x + 15
  2. −2(4 − 3x) = −8 + 6x, tidied to 6x − 8
  3. 4x(2x − 3) = 8x² − 12x

3x + 15, 6x − 8, 8x² − 12x

2.2 Double brackets (FOIL)

Two brackets multiply as First, Outer, Inner, Last: multiply every term in the first bracket by every term in the second, then collect like terms.

(x + a)(x + b) = x² + (a + b)x + ab
Worked example 4

Expand and simplify (x + 3)(x + 4), then (2x − 1)(x + 5).

  1. First: x × x = x²
  2. Outer and inner: 4x + 3x = 7x
  3. Last: 3 × 4 = 12, so (x + 3)(x + 4) = x² + 7x + 12
  4. Second: 2x² + 10x − x − 5 = 2x² + 9x − 5

x² + 7x + 12 and 2x² + 9x − 5

2.3 Perfect squares and difference of squares

(x + a)² = x² + 2ax + a² · (a + b)(a − b) = a² − b²

A perfect square is a double bracket with the same bracket twice. It gives three terms: square the first, double the product, square the last. The difference of squares gives two terms, because the middle term cancels.

Worked example 5

Expand (x + 5)² and (3x + 2)(3x − 2).

  1. Perfect square: x² + 2(5)x + 5² = x² + 10x + 25
  2. Difference of squares with a = 3x, b = 2: (3x)² − 2² = 9x² − 4
  3. Check the middle really cancels: 9x² − 6x + 6x − 4 = 9x² − 4

x² + 10x + 25 and 9x² − 4

Exam trap(x + 4)² = x² + 8x + 16, never x² + 16. Writing (x + a)² as x² + a² is one of the most common errors in the whole paper.
Exam tipExpand first, then simplify. If the question says "expand and simplify", the mark scheme wants the brackets gone and like terms collected in one line of working.

3. Factorising

Factorising is expanding in reverse: you are writing an expression as a product of brackets. Always try in this order: common factor first, then a pattern (difference of squares), then a quadratic pair of brackets.

Factorise or solve?Factorise means "write it as brackets" and the answer is an expression, e.g. x² + 5x + 6 = (x + 2)(x + 3). Solve means "find the value of x" and the answer is numbers, e.g. x = −2 or x = −3. Read the command word carefully, marks depend on it.

3.1 Common factor

6x + 9 = 3(2x + 3) · 4x² − 10x = 2x(2x − 5)

Take out the biggest number that divides every term, and every letter that appears in every term.

3.2 Factorising x² + bx + c

x² + bx + c = (x + p)(x + q) where p + q = b and p × q = c

Find two numbers that multiply to give c and add to give b. Watch the signs: if c is positive the two numbers have the same sign; if c is negative they have opposite signs.

3.3 Non-monic: ax² + bx + c

When the x² term has a number in front, multiply a × c, find two numbers that multiply to ac and add to b, split the middle term, then factorise in pairs.

3.4 Difference of squares

x² − a² = (x − a)(x + a) · 4x² − 25 = (2x − 5)(2x + 5)
Worked example 6

Factorise fully: 6x + 9, x² + 7x + 12, x² − 25.

  1. Common factor: highest common factor of 6 and 9 is 3, so 6x + 9 = 3(2x + 3)
  2. Quadratic: two numbers multiplying to 12 and adding to 7 are 3 and 4, so x² + 7x + 12 = (x + 3)(x + 4)
  3. Pattern: it is x² − 5², so x² − 25 = (x − 5)(x + 5)

3(2x + 3), (x + 3)(x + 4), (x − 5)(x + 5)

Worked example 7

Factorise 6x² + 7x − 3.

  1. a × c = 6 × (−3) = −18. Find two numbers multiplying to −18 and adding to +7: +9 and −2
  2. Split the middle term: 6x² + 9x − 2x − 3
  3. Factorise in pairs: 3x(2x + 3) − 1(2x + 3)
  4. Take out the common bracket: (2x + 3)(3x − 1)
  5. Check by expanding: 6x² − 2x + 9x − 3 = 6x² + 7x − 3 ✓

6x² + 7x − 3 = (2x + 3)(3x − 1)

Worked example 8

Factorise fully: 3x² − 48 and 2x² − 7x + 3.

  1. Common factor first: 3x² − 48 = 3(x² − 16) = 3(x − 4)(x + 4)
  2. For 2x² − 7x + 3: a × c = 6, numbers adding to −7 are −6 and −1
  3. Split: 2x² − 6x − x + 3 = 2x(x − 3) − 1(x − 3)
  4. Result: (2x − 1)(x − 3). Check: 2x² − 6x − x + 3 ✓

3(x − 4)(x + 4) and (2x − 1)(x − 3)

Exam tip"Factorise fully" means keep going until no common factor or pattern is left. 3x² − 48 is not finished at 3(x² − 16), and 2x + 4 is not finished at 2(x + 2) if the question wants every number out.
Exam trapx² + 5x + 6 needs a + in both brackets, x² − 5x + 6 needs a − in both, and x² + x − 6 needs one of each. The sign of b and c tells you which.

4. Solving linear equations

An equation is a balance. Whatever you do to one side, do to the other. The strategy is always: undo the operations in reverse order, collecting the unknown on one side and the numbers on the other.

reverse order: undo + and − last, undo × and ÷ first, brackets before anything inside them

4.1 One bracket, or one unknown only

Worked example 9

Solve 3x + 7 = 22 and 5(x − 2) = 3x + 4.

  1. First equation: subtract 7 from both sides, 3x = 15
  2. Divide by 3: x = 5. Check: 3(5) + 7 = 22 ✓
  3. Second equation: expand first, 5x − 10 = 3x + 4
  4. Subtract 3x and add 10: 2x = 14, so x = 7
  5. Check: 5(7 − 2) = 25 and 3(7) + 4 = 25 ✓

x = 5 and x = 7

4.2 Unknown on both sides

Collect every x on one side and every number on the other, then divide once. Move the smaller x term across if you want to keep the coefficient positive.

Worked example 10

Solve 5x − 3 = 2x + 9.

  1. Subtract 2x from both sides: 3x − 3 = 9
  2. Add 3 to both sides: 3x = 12
  3. Divide by 3: x = 4
  4. Check both sides: 5(4) − 3 = 17 and 2(4) + 9 = 17 ✓

x = 4

4.3 Equations with fractions

Find the lowest common denominator of every fraction in the equation and multiply every term (both sides, including ones with no fraction) by it. The fractions vanish.

Worked example 11

Solve (2x + 1)/3 = (x − 1)/2.

  1. Lowest common denominator of 3 and 2 is 6. Multiply every term by 6
  2. 2(2x + 1) = 3(x − 1)
  3. Expand: 4x + 2 = 3x − 3
  4. Collect: x = −5
  5. Check: LHS (2(−5) + 1)/3 = −9/3 = −3; RHS (−5 − 1)/2 = −6/2 = −3 ✓

x = −5

4.4 Word problems

Worked example 12

Three notebooks and two pens cost £4.10. One notebook and four pens cost £4.70. Find the price of each item.

  1. Let a notebook cost n pence and a pen cost p pence. Write 410 and 470 in pence
  2. 3n + 2p = 410 and n + 4p = 470
  3. From the second, n = 470 − 4p. Substitute into the first: 3(470 − 4p) + 2p = 410
  4. 1410 − 12p + 2p = 410, so −10p = −1000 and p = 100
  5. n = 470 − 400 = 70

Notebook = 70p, pen = £1.00

Exam tipAlways substitute your answer back into the original equation. A check takes ten seconds and catches a sign error before the examiner does. For word problems, finish with a sentence and the units stated in the question.
Exam trapWhen you multiply through by an LCD, multiply every term, not just the fractions. And when you move a term across the equals sign, flip its sign: 3x − 3 = 9 becomes 3x = 12 by adding 3, not by writing 9 − 3 in the wrong place.

5. Making the subject of a formula

The subject is the letter standing alone on one side. To make a different letter the subject, undo the operations applied to it, in reverse, doing the same thing to both sides. The letter you want must end up alone.

y = 3x + 5 → y − 5 = 3x → x = y − 53

5.1 One-step and two-step rearrangements

Worked example 13

Make x the subject of y = 3x + 5, then of y = (x − 4)/2.

  1. First: subtract 5, y − 5 = 3x
  2. Divide by 3: x = (y − 5)/3
  3. Second: multiply by 2 to clear the fraction, 2y = x − 4
  4. Add 4: x = 2y + 4

x = (y − 5)/3 and x = 2y + 4

5.2 The subject appears twice

If the letter you want is in two places, you cannot collect it by adding. Expand first, then collect the subject terms on one side, then factorise the subject out, then divide.

Worked example 14

Make x the subject of y = 2x/(x + 1).

  1. Multiply both sides by x + 1: y(x + 1) = 2x
  2. Expand: yx + y = 2x
  3. Collect every x term on one side: y = 2x − yx
  4. Factorise x out: y = x(2 − y)
  5. Divide by the bracket: x = y/(2 − y)
  6. Check with y = 1: x = 1/(2 − 1) = 1, and 2(1)/(1 + 1) = 1 ✓

x = y/(2 − y)

Exam tipThe recipe for "x in two places": expand brackets, move all x terms to one side, factorise x out, divide. Never divide by x early, and never add the two x terms together as if they were like terms.
Exam trapKeep brackets around a substituted expression: x = (y − 5)/3 must be written with the numerator in brackets when you write it as a fraction. Dropping them turns (y − 5)/3 into y − 5/3, which is a different thing entirely.

6. Simultaneous equations

Two equations with two unknowns have one pair of values that satisfies both at once. There are two methods, and the question usually decides which is quicker.

MethodUse it whenMove
EliminationBoth equations are in the form ax + by = cLine them up, multiply so a coefficient matches, add or subtract
SubstitutionOne equation is already x = ... or y = ...Plug that expression into the other equation

6.1 Elimination

Worked example 15

Solve 2x + y = 11 and x − y = 1.

  1. Line them up. The y coefficients are already +1 and −1
  2. Add the equations: 3x = 12, so x = 4
  3. Substitute into x − y = 1: 4 − y = 1, so y = 3
  4. Check in the first equation: 2(4) + 3 = 11 ✓

x = 4, y = 3

If the coefficients do not match, multiply one or both equations first. For 3x + 2y = 16 and 4x + 3y = 22, multiply the first by 3 and the second by 2 to make both y coefficients 6, then subtract: 9x + 6y = 48 and 8x + 6y = 44, so x = 4, then 2y = 16 − 12 gives y = 2.

6.2 Substitution

Worked example 16

Solve y = 2x − 1 and 3x + y = 9.

  1. The first equation already gives y, so substitute it into the second
  2. 3x + (2x − 1) = 9
  3. 5x − 1 = 9, so 5x = 10 and x = 2
  4. y = 2(2) − 1 = 3
  5. Check in both: 3(2) + 3 = 9 ✓ and y = 3 ✓

x = 2, y = 3

6.3 Word problem, and what the answer means

Worked example 17

Three coffees and two cakes cost £11.00. One coffee and four cakes cost £10.00. Find the price of a coffee and the price of a cake.

  1. Let coffee = c pence, cake = k pence: 3c + 2k = 1100 and c + 4k = 1000
  2. From the second, c = 1000 − 4k
  3. Substitute: 3(1000 − 4k) + 2k = 1100 → 3000 − 12k + 2k = 1100
  4. −10k = −1900, so k = 190
  5. c = 1000 − 760 = 240. Check: 3(240) + 2(190) = 720 + 380 = 1100 ✓

Coffee = £2.40, cake = £1.90

The graph meaningThe solution pair is the point where the two straight lines cross. If the lines are parallel there is no solution; if they are the same line there are infinitely many. This idea returns in coordinate geometry.
Exam trapAlways check your pair in both original equations. A sign slip during elimination gives a pair that fixes the equation you used and breaks the other one. Also write answers as "x = 4, y = 3", not just "7 and 4".

7. Quadratic equations and graphs

A quadratic has an x² term, so it can have two solutions, one, or none. In this syllabus you solve by factorising or by the quadratic formula. Completing the square is not needed and will not be examined.

7.1 Solving by factorising

x² − 5x + 6 = 0 → (x − 2)(x − 3) = 0 → x = 2 or x = 3

If two brackets multiply to give zero, at least one bracket must be zero. Set each bracket equal to zero separately and you get both roots. Remember to set the equation to zero first: x² = 5x − 6 must become x² − 5x + 6 = 0.

Worked example 18

Solve x² − 5x + 6 = 0, then 2x² + 5x = 3.

  1. First: numbers multiplying to +6 and adding to −5 are −2 and −3, so (x − 2)(x − 3) = 0
  2. Set each bracket to zero: x = 2 or x = 3
  3. Second: subtract 3, 2x² + 5x − 3 = 0
  4. a × c = −6, numbers adding to 5 are 6 and −1: 2x² + 6x − x − 3 = 0
  5. 2x(x + 3) − 1(x + 3) = 0, so (2x − 1)(x + 3) = 0
  6. x = ½ or x = −3

x = 2 or x = 3; and x = ½ or x = −3

7.2 The quadratic formula

When it will not factorise neatly, use the formula. Write the equation as ax² + bx + c = 0 first and read off a, b and c with their signs.

x = −b ± √(b² − 4ac)2a
Worked example 19

Solve 2x² + 3x − 5 = 0 using the formula.

  1. a = 2, b = 3, c = −5
  2. b² − 4ac = 9 − 4(2)(−5) = 9 + 40 = 49
  3. √49 = 7
  4. x = (−3 ± 7) / 4
  5. Take the plus: x = 4/4 = 1. Take the minus: x = −10/4 = −2.5
  6. Check: 2(1)² + 3(1) − 5 = 0 ✓ and 2(6.25) + 3(−2.5) − 5 = 12.5 − 7.5 − 5 = 0 ✓

x = 1 or x = −2.5

7.3 The discriminant

The bit under the square root, b² − 4ac, is the discriminant. It tells you how many real roots there are before you even finish the calculation.

DiscriminantMeaningRoots
b² − 4ac > 0Positive, and a perfect square if the roots are rationalTwo distinct real roots
b² − 4ac = 0Zero, the square root vanishesOne repeated root (the graph touches the x-axis)
b² − 4ac < 0Negative, you cannot square-root itNo real roots
Worked example 20

How many real roots does x² + 2x + 5 = 0 have? And x² − 6x + 9 = 0?

  1. First: b² − 4ac = 4 − 4(1)(5) = 4 − 20 = −16
  2. It is negative, so no real roots
  3. Second: 36 − 36 = 0, so one repeated root, x = 3

First: no real roots. Second: one root, x = 3

7.4 Facts about the graph y = ax² + bx + c

  • Opening: a parabola (U-shape). It opens upwards if a > 0 and downwards if a < 0.
  • y-intercept: put x = 0, the graph crosses at (0, c).
  • x-intercepts: put y = 0, these are the roots of the equation.
  • Axis of symmetry: the vertical mirror line through the turning point,
    x = −b2a
Worked example 21

For y = x² − 5x + 6, state the y-intercept, the roots and the axis of symmetry.

  1. a = 1 > 0 so the parabola opens upwards
  2. y-intercept: c = 6, so it crosses at (0, 6)
  3. Roots: (x − 2)(x − 3) = 0 gives x = 2 and x = 3
  4. Axis: x = −b/(2a) = 5/2 = 2.5, halfway between the roots

Opens up, crosses y-axis at 6, x-axis at 2 and 3, axis of symmetry x = 2.5

Exam tipThe axis of symmetry always sits halfway between the two roots. Use that as a quick check of your answer. Always give both roots unless the question says "the positive root".
Exam trapb in the formula carries its own sign. In x² − 5x + 6 you have b = −5, so −b = +5. Also, a negative discriminant means "no real roots", not "no solutions".

8. Indices laws

Indices (powers) obey six laws. Learn them as a set: they turn messy multiplication into simple addition of powers.

Worked example 22

Simplify (2x³y²)³ ÷ (4x³y).

  1. Power of a product: (2x³y²)³ = 2³x9y6 = 8x⁹y⁶
  2. Divide: 8 ÷ 4 = 2
  3. Subtract powers of x: x9−3 = x⁶
  4. Subtract powers of y: y6−1 = y⁵

2x⁶y⁵

Worked example 23

Evaluate 253/2 and 8−2/3.

  1. Denominator is the root: 253/2 = (√25)³
  2. √25 = 5, so 5³ = 125
  3. For the second, deal with the minus first: 8−2/3 = 1 / 82/3
  4. 82/3 = (∛8)² = 2² = 4, so the answer is 1/4

253/2 = 125 and 8−2/3 = 0.25

Exam tipWrite √a as a1/2 and ∛a as a1/3 whenever you need to combine it with other powers. Everything then runs on the same six laws.
Exam trapYou can only add powers when multiplying like bases, and only if the base is identical: x³ × x⁴ = x⁷ but x³ + x⁴ cannot be simplified at all. (3x)² = 9x², not 3x².

9. Inequalities

An inequality is like an equation, but the answer is a range of values rather than one number.

SymbolReads asIncludes the endpoint?
<less thanNo
>greater thanNo
≤less than or equal toYes
≥greater than or equal toYes

9.1 Solving like an equation

Add or subtract from both sides exactly as with an equation. The one extra rule is the flip rule.

When you multiply or divide BOTH sides by a NEGATIVE number, FLIP the inequality sign.
Worked example 24

Solve 3x − 4 > 11 and −2x ≤ 6.

  1. First: add 4, 3x > 15
  2. Divide by +3 (positive, no flip): x > 5
  3. Second: divide by −2, which is negative, so flip the sign
  4. x ≥ −3
  5. Check with x = −4, which is not in the solution: −2(−4) = 8, and 8 is not ≤ 6 ✓ (so −4 is correctly excluded)

x > 5 and x ≥ −3

9.2 Drawing the solution on a number line

  • Solid (filled) dot for ≤ and ≥ because the endpoint is included.
  • Hollow (open) circle for < and > because the endpoint is excluded.
  • Shade or draw the line in the direction the inequality points: x > 5 shades to the right of 5.

9.3 Double inequalities

Treat all three parts at once, doing the same thing to each part. Never flip only the middle.

Worked example 25

Solve −1 < 2x + 3 ≤ 7 and describe the number-line picture.

  1. Subtract 3 from all three parts: −4 < 2x ≤ 4
  2. Divide all three parts by +2 (positive, so no flip): −2 < x ≤ 2
  3. Number line: hollow circle at −2, solid dot at 2, line shaded between them

−2 < x ≤ 2: open at −2, closed at 2, shaded in between

Exam trapMultiplying or dividing by a variable you assume is positive is not allowed without justification. Only flip when the number you divide by is definitely negative. If you ever multiply a bracket by −1, flip the sign in the same line.
Exam tipFix the symbol names in your head: open circle means "not included", filled dot means "included". The question "write down the inequality shown on this number line" is usually one easy mark, so read the dot type first.

10. Proportionality

Proportion questions describe a relationship in words. Translate the words into a formula, use the given pair of values to find k, then use k to answer the question.

Exam wordingFormula
y is directly proportional to xy = kx
y is proportional to the square of xy = kx²
y is proportional to the cube root of xy = k x1/3
y is inversely proportional to xy = k/x
y is inversely proportional to the square of xy = k/x²
y = kx (direct) · y = k/x (inverse) · k = y ÷ x or k = y × x

10.1 Direct proportion

Worked example 26

y is proportional to the square of x. Given y = 20 when x = 2, find y when x = 4.

  1. Translate: y = kx²
  2. Substitute the known pair: 20 = k(2)² = 4k
  3. Find k: k = 5, so the formula is y = 5x²
  4. Use it: y = 5(4)² = 5 × 16 = 80

k = 5 and y = 80

10.2 Inverse proportion

Worked example 27

y is inversely proportional to x. Given y = 8 when x = 5, find x when y = 10.

  1. Translate: y = k/x
  2. Substitute: 8 = k/5, so k = 40
  3. Formula: y = 40/x
  4. Use it: 10 = 40/x, so x = 4

k = 40 and x = 4

Exam tipTwo marks are almost always available: one for writing y = kx² (or the right form) and one for the value of k. State k explicitly, even if the question never asks for it.
Exam trap"Directly proportional" gives y = kx, never y = kx + b. There is no constant added in proportionality questions. And "inversely proportional to x" means y = k/x, not y = −kx.

11. Practice set and answers

Do every question on paper first. Open an answer only after you have committed to one.

Set A · Simplifying, expanding, factorising

Simplify: 7a + 3b − 2a + 5b − a²
Collect like terms: 7a − 2a = 5a and 3b + 5b = 8b. a² has no partner. Answer: 5a + 8b − a² (tidied as −a² + 5a + 8b).
Expand and simplify: (x + 6)(x − 2)
First x², outer −2x, inner 6x, last −12. x² + 4x − 12. Answer: x² + 4x − 12.
Expand and simplify: (2x − 3)²
Perfect square: (2x)² + 2(2x)(−3) + (−3)² = 4x² − 12x + 9. Answer: 4x² − 12x + 9. Not 4x² + 9.
Factorise: 12x² − 18x
Common factor of 6 and x: Answer: 6x(2x − 3).
Factorise: x² − 9x + 20
Multiplies to 20, adds to −9: −4 and −5. Answer: (x − 4)(x − 5).
Factorise: 6x² + 7x − 3
a × c = −18, add to 7: +9 and −2. Split: 6x² + 9x − 2x − 3 = 3x(2x + 3) − 1(2x + 3). Answer: (2x + 3)(3x − 1).
Factorise fully: 5x² − 125
Common factor 5 first: 5(x² − 25), then difference of squares. Answer: 5(x − 5)(x + 5).

Set B · Equations, subjects, simultaneous equations

Solve: 4(x − 2) = 2x + 6
Expand: 4x − 8 = 2x + 6. 2x = 14. Answer: x = 7. Check 4(5) = 20 and 2(7) + 6 = 20 ✓.
Solve: (3x − 1)/4 = (x + 5)/6
LCD 12: 3(3x − 1) = 2(x + 5) → 9x − 3 = 2x + 10 → 7x = 13. Answer: x = 13/7 (about 1.86).
Make t the subject of v = u + at
Subtract u: v − u = at. Divide by a. Answer: t = (v − u)/a.
Make x the subject of y = 3x/(x − 2)
Multiply: y(x − 2) = 3x → yx − 2y = 3x → collect x: −2y = 3x − yx = x(3 − y) → divide. Answer: x = −2y/(3 − y), which also equals 2y/(y − 3).
Solve: x + y = 7 and 3x − y = 5
Add the equations: 4x = 12, so x = 3. Then y = 4. Check 3(3) − 4 = 5 ✓. Answer: x = 3, y = 4.
Solve: y = x + 1 and 2x + 3y = 16
Substitute: 2x + 3(x + 1) = 16 → 5x + 3 = 16 → 5x = 13, so x = 2.6 and y = 3.6. Check: 2(2.6) + 3(3.6) = 5.2 + 10.8 = 16 ✓. Answer: x = 2.6, y = 3.6.

Set C · Quadratics, indices, inequalities, proportion

Solve: x² − 7x + 12 = 0
Multiplies to 12, adds to −7: −3 and −4. (x − 3)(x − 4) = 0. Answer: x = 3 or x = 4.
Solve to 3 significant figures: x² + 4x − 3 = 0
Not factorisable. a = 1, b = 4, c = −3, discriminant 16 + 12 = 28, √28 = 5.292. x = (−4 ± 5.292)/2. Answer: x = 0.646 or x = −4.646 (so x = 0.646 or x = −4.65 to 3 s.f.).
How many real roots does 3x² − 2x + 5 = 0 have?
b² − 4ac = 4 − 4(3)(5) = 4 − 60 = −56, which is negative. Answer: no real roots.
Simplify: x⁵ × x³ ÷ x⁴
Add then subtract powers: x8 ÷ x⁴ = x⁴. Answer: x⁴.
Evaluate: 163/4
Fourth root first: 161/4 = 2, then cube: 2³ = 8. Answer: 8.
Solve: −3x + 2 < 11, and show it on a number line
Subtract 2: −3x < 9. Divide by −3 and flip: Answer: x > −3. Hollow circle at −3, shaded to the right.
y is inversely proportional to x. y = 12 when x = 3. Find y when x = 8.
y = k/x → 12 = k/3 → k = 36. So y = 36/8 = 4.5. Answer: y = 4.5.
A is proportional to b². A = 45 when b = 3. Find b when A = 200.
A = kb² → 45 = 9k → k = 5. So 200 = 5b² → b² = 40 → b = √40 = 6.32 to 3 s.f. Answer: b = 6.32.
For y = −2x² + 8x − 3, state the y-intercept, the direction of opening and the axis of symmetry.
a = −2 < 0 so it opens downwards. y-intercept is c = −3. Axis: x = −b/(2a) = −8/(−4) = 2. Answer: crosses the y-axis at −3, opens down, axis x = 2.
Three t-shirts and one hoodie cost £42. One t-shirt and two hoodies cost £46. Find each price.
Let t-shirt = t, hoodie = h: 3t + h = 42 and t + 2h = 46. From the first, h = 42 − 3t. Substitute: t + 2(42 − 3t) = 46 → 84 − 5t = 46 → 5t = 38 → t = 7.60. Then h = 42 − 22.80 = 19.20. Check: 7.60 + 38.40 = 46 ✓. Answer: T-shirt £7.60, hoodie £19.20.

12. Exam checklist

  • Collected only like terms, and left unlike terms alone.
  • Substituted with brackets and did powers before multiplying.
  • Expanded every term in the bracket, then tidied up.
  • Wrote (x + a)² = x² + 2ax + a² with the middle term, not just two terms.
  • Factorised the common factor first, then looked for a pattern, then a pair of brackets.
  • Used "multiply to c, add to b" (or a × c for non-monic) and checked by expanding.
  • Set the equation to zero before factorising a quadratic.
  • Set each bracket equal to zero and gave both roots.
  • Used the quadratic formula with b taken with its sign, and gave answers to the accuracy asked for.
  • Checked b² − 4ac when asked how many roots, and used "no real roots" for a negative value.
  • Multiplied an equation with fractions by the LCD, including the terms without fractions.
  • Read the command word: factorise means brackets, solve means find x.
  • When making the subject, collected the subject's terms on one side and factorised it out.
  • Checked simultaneous equation pairs in both original equations.
  • Flipped the inequality sign only when multiplying or dividing by a negative.
  • Drew solid dots for ≤ and ≥, hollow circles for < and >.
  • Translated proportion wording into y = kxⁿ or y = k/xⁿ before substituting.
  • Gave answers in context with units on word problems.
