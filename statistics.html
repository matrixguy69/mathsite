Chapter 01 · Statistics

Mean, mode, median, range and scatter diagrams

Everything from the three Zainematics statistics lessons, worked in full: measures of central tendency from raw data and frequency tables, outliers, correlation, and the line of best fit.

Lesson · 47 min Practice · 21 min Scatter plots · 28 min

1. Averages and spread, the big picture

Statistics questions always give you data: a list of values, a tally or frequency table, or a graph. You are asked to summarise that data with a small number of values, or to describe the pattern it shows. There are four summaries you must know cold.

MeasureAnswers the questionHow to find it
MeanWhat is the balance point of all the data?Sum of all values ÷ number of values
ModeWhat value comes up most often?The value with the highest frequency
MedianWhat is the middle value?Order the data, take the middle
RangeHow spread out is the data?Largest value − smallest value
The golden rule of statistics questionsAlways order the data before you touch the median or quartiles. Every year, marks are thrown away by finding the middle of an unordered list.

2. The mean (average)

The mean is the value every data point would need to be for the total to stay the same. It uses every value, so one unusual value (an outlier) can drag it away from the typical value.

2.1 Mean of raw data

mean = sum of all valuesnumber of values = Σx / n

Σ (sigma) means "add up". n is how many values there are.

Worked example 1

Marks out of 10: 2, 5, 5, 7, 6. Find the mean.

  1. Add the values: 2 + 5 + 5 + 7 + 6 = 25
  2. Count them: n = 5
  3. Divide: 25 ÷ 5 = 5

Mean = 5 marks

2.2 Mean from a frequency table

When values repeat, a frequency table lists each value x once with its frequency f (how many times it occurs). Adding up the frequency column gives n. Multiply each x by its f to get fx, then:

mean = Σ(fx) / Σf
Worked example 2

Number of goals scored by a team in each match:

Goals (x)01234
Matches (f)25643
  1. Column of fx: 0, 5, 12, 12, 12
  2. Σfx = 0 + 5 + 12 + 12 + 12 = 41
  3. Σf = 2 + 5 + 6 + 4 + 3 = 20
  4. mean = 41 / 20 = 2.05

Mean = 2.05 goals per match

2.3 Assumed (coded) mean

For long tables with big values, use a shorter method. Pick an assumed mean A near the centre of the x values, form d = x − A, then:

mean = A + Σ(fd) / Σf
Worked example 3

Data: x = 12, 16, 20, 24 with f = 3, 5, 4, 8. Take A = 20.

  1. d = x − 20 gives −8, −4, 0, 4
  2. fd = −24, −20, 0, 32, so Σ(fd) = −12
  3. Σf = 20, so mean = 20 + (−12/20) = 20 − 0.6

Mean = 19.4

Exam tipChoose A as one of the middle x values so the d column stays small. The coded method always gives the same answer as the Σfx method if you are careful with negatives.

3. Mode and modal class

The mode is the value that occurs most often. It is the only average you can use for non-numerical data such as "most popular shoe size" or "favourite colour".

  • From a list: count how often each value appears, take the winner.
    Worked example 4

    3, 5, 7, 5, 9, 5, 2 → 5 appears three times, more than anything else. Mode = 5. Every other value appears once.

  • From a frequency table: the mode is the x with the largest f.
  • From grouped data: you can only name the modal class, the group with the highest frequency. You cannot give a single exact value.
  • Data can have no mode (nothing repeats), one mode, or two modes (bimodal, e.g. "1 and 3 are both modes").

4. The median

The median is the middle value once the data is in order. It is resistant to outliers, which is why house prices and salaries are reported using medians.

position of median = (n + 1) / 2

4.1 Odd number of values

Worked example 5

Find the median of 9, 3, 7, 11, 5.

  1. Order it: 3, 5, 7, 9, 11
  2. Position: (5 + 1) / 2 = 3rd value
  3. 3rd value is 7

Median = 7

4.2 Even number of values

There is no single middle value, so average the two in the middle.

Worked example 6

Find the median of 2, 8, 4, 6.

  1. Order it: 2, 4, 6, 8
  2. Position: (4 + 1) / 2 = 2.5, halfway between the 2nd and 3rd
  3. Average: (4 + 6) / 2 = 5

Median = 5

4.3 Median from a frequency table

Build a cumulative frequency column (running total of f). The median is the value at position n / 2 inside that running total. Read it off a cumulative frequency graph, or interpolate inside the median class (see below).

Worked example 7

Scores:

Score1–56–1011–1516–20
f2486
  1. Cumulative frequencies: 2, 6, 14, 20, so n = 20
  2. Median position n / 2 = 10. The 10th value sits in the 11–15 class (which runs from the 7th to the 14th value).
  3. Interpolating (assume values spread evenly): the median class is 11–15, boundary 10.5, and
    median = 10.5 + 10 − 68 × 5 = 10.5 + 2.5 = 13

Median = 13

Interpolation, the general formInside a class that starts at boundary L with frequency f and width w, when the cumulative frequency before it is F:
value = L + position − Ff × w

5. Range, quartiles and the IQR

range = largest value − smallest value
Worked example 8

Heights (cm): 150, 162, 158, 171, 199. Range = 199 − 150 = 49 cm. Note the 199 is an outlier, so the range looks huge even though four of the five people are between 150 and 171.

The range only uses two values, so it is easily distorted. The quartiles split ordered data into four equal parts and give a fairer measure of spread.

  • Q1 (lower quartile): the median of the lower half. Position (n + 1) / 4.
  • Q2: the median itself. Position (n + 1) / 2.
  • Q3 (upper quartile): the median of the upper half. Position 3(n + 1) / 4.
  • Interquartile range: IQR = Q3 − Q1. It ignores the extreme quarters, so outliers barely touch it.
Worked example 9

Data: 4, 7, 9, 10, 12, 15, 18, 21, 25, 30 (n = 10).

  1. Already ordered. Q1 position: (10 + 1) / 4 = 2.75 → between 2nd and 3rd: 7 + 0.75(9 − 7) = 8.5
  2. Median position 5.5: (12 + 15) / 2 = 13.5
  3. Q3 position: 3(10 + 1) / 4 = 8.25 → between 8th and 9th: 21 + 0.25(25 − 21) = 22
  4. IQR = 22 − 8.5 = 13.5

Q1 = 8.5, median = 13.5, Q3 = 22, IQR = 13.5

Exam trapSome papers use n / 4 style positions instead of (n + 1) / 4. If your answer seems close to a method boundary, write out which position formula you used and stick to it consistently within the question.

6. Choosing the right measure

The exam loves "which measure is most suitable? Justify your answer." You must name the measure and give the reason.

SituationBest measureWhy
House prices in a streetMedianOne mansion would wreck the mean
Wages at a companyMedianThe boss's salary is an outlier
Typical score in a testMeanUses every mark, rewards consistency
Most popular T-shirt sizeModeOnly sizes that sell matter
How consistent an athlete isRange or IQRMeasures spread, not centre
Outliers: effects to memorise
  • Add a huge outlier: the mean rises, the median barely moves, the range explodes.
  • A test for an outlier: any value more than 1.5 × IQR below Q1 or above Q3 is often called an outlier.
Worked example 10

A teacher compares her salary with her 20 colleagues. Which average should she report, and why?

The median: salaries often include very high earners, and these outliers would distort the mean. The median describes a typical salary honestly.

7. Scatter diagrams and correlation

Scatter diagrams show the relationship between two variables at once. Each dot is one pair (x, y).

7.1 Drawing one

  1. Choose sensible axes and label them with the variables and their units.
  2. Use even scales. If your data starts at 80, you may start the axis at 80 instead of 0, but you must show the scale clearly.
  3. Plot each pair as a small cross or dot and check you have one mark per pair.

7.2 Describing correlation

TypeWhat the points doReal example
PositiveGo uphill left to right: y rises as x risesHeight vs weight
NegativeGo downhill left to right: y falls as x risesSpeed vs journey time
No correlationNo pattern at allShoe size vs eye colour

Also describe strength. Points tight around a clear trend line are strong. Points loosely scattered are weak. Full marks come from both words together:

Model answers"There is a strong positive correlation between height and weight." · "There is a weak negative correlation between journey time and speed." · "There is no correlation between age and favourite subject."
Exam trapCorrelation is not causation. Two things rising together does not prove one causes the other, and an outlier can hide or reverse a real trend. Comment on outliers when the question hints at them.

8. The line of best fit

When correlation exists, you draw one straight line of best fit through the points by eye.

  • It runs through the middle of the band of points, with roughly half the points above and half below.
  • It follows the general direction of the points.
  • It does not have to pass through the origin (0, 0) or through any particular point.
  • If the points show no correlation, do not force a line. Say so.
Worked example 11

A scatter diagram plots revision hours against test marks. The dots climb steadily with little scatter. Draw a line of best fit, then read off the mark for a student who revised 6 hours.

  1. Correlation is strong positive.
  2. Draw a ruler line through the centre of the dots, balancing points above and below.
  3. From 6 hours on the x-axis, move up to the line, then across to the mark axis: the value read off is the prediction.

Prediction read from the line, stated in marks.

9. Predicting values: interpolation and extrapolation

What it isHow reliable?
InterpolationPredicting a value inside the range of the data you were givenYes, reasonably reliable
ExtrapolationPredicting a value outside that rangeRisky: the trend may stop or reverse
Worked example 12

Heights of children aged 5 to 11 are plotted. Can you use the line of best fit to predict the height of a 25-year-old?

No. Twenty-five is far outside the 5 to 11 range, so it is extrapolation. People stop growing, so the trend cannot be assumed to continue.

Prediction methodFrom the known value on the x-axis, go straight up (or down) to your line of best fit, then straight across to the y-axis. Read the value, and always give it a context and units, e.g. "about 42 kg".

10. Practice set and answers

Do every question on paper first. Open an answer only after you have committed to one.

Set A · Mean, mode, median, range

Find the mean, mode, median and range of: 4, 7, 9, 7, 11, 15, 7
Mean = 60 ÷ 7 = 8.57 (2 dp). Mode = 7 (appears three times). Ordered: 4, 7, 7, 7, 9, 11, 15, so median = 4th value = 7. Range = 15 − 4 = 11.
x = 10, 20, 30 with frequencies 4, 6, 2. Find the mean and the mode.
Σfx = 40 + 120 + 60 = 220, Σf = 12, mean = 220 ÷ 12 = 18.3 (1 dp). Mode = 20 (highest frequency, 6).
Data: 3, 6, 8, 9, 12, 15. Find the median.
Ordered already. Position (6 + 1) ÷ 2 = 3.5, halfway between 8 and 9. Median = 8.5.
A shop sells 50 prices of tea: range £1 to £80, median £2.50, mean £6. Which average best describes a typical price, and why?
Median £2.50. The £80 item is an outlier, dragging the mean up. Only the median resists it.
Find the coded mean of 12, 16, 20, 24 with f = 3, 5, 4, 8, using A = 20.
d = −8, −4, 0, 4. Σ(fd) = −24 − 20 + 0 + 32 = −12. Σf = 20. Mean = 20 − 12/20 = 19.4.
Find the mode and modal class from: 10×4, 20×7, 30×9, 40×3.
Mode = 30 (frequency 9, the highest). For grouped data you would state the modal class only, e.g. "30–40".

Set B · Quartiles, spread, choosing measures

Ordered data: 2, 5, 7, 9, 11, 14, 16, 20, 23, 28. Find Q1, median, Q3 and the IQR.
n = 10. Q1 at position 2.75: 7 + 0.75(9 − 7) = 8.5. Median at 5.5: (11 + 14) ÷ 2 = 12.5. Q3 at position 8.25: 20 + 0.25(23 − 20) = 20.75. IQR = 20.75 − 8.5 = 12.25.
Which measure of spread would you use if the data contains a clear outlier? Why?
IQR: it is based on the middle half of the data, so outliers in the extremes are ignored. The range would be inflated by them.
Heights: Q1 = 160, Q3 = 176. Are heights of 148 cm and 198 cm outliers?
IQR = 16. Lower fence: 160 − 1.5(16) = 136. Upper fence: 176 + 1.5(16) = 200. 148 is above 136 and 198 is below 200, so neither is an outlier.

Set C · Scatter diagrams and lines of best fit

Name the correlation: as temperature rises, ice cream sales rise.
Positive correlation (state "strong" or "weak" too if you can see the scatter).
As hours of TV watched increase, test marks decrease. Name the correlation.
Negative correlation.
Plotting shoe size against favourite colour shows scattered dots. What is the correlation?
No correlation.
A child's age is plotted against height from ages 2 to 8. Predict the height of a 30-year-old. Comment.
Do not predict: it is far outside the data, pure extrapolation, and adults stop growing.
Give two rules for drawing a good line of best fit.
It is a straight line through the middle of the points, with about half the points above and half below, following the trend. It does not have to pass through the origin.

11. Exam checklist

  • Ordered the data before touching the median or quartiles.
  • Used Σfx ÷ Σf for a frequency table mean, and showed the fx column.
  • Stated units and context on every answer ("2.05 goals per match", not just "2.05").
  • Named the measure and justified it whenever the question says "most suitable".
  • Described correlation with both type and strength.
  • Checked whether a prediction is interpolation (safe) or extrapolation (risky).
  • Labelled scatter diagram axes with variables and units, with even scales.
  • Commented on outliers when the data contains one.
